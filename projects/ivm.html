Forest Service Interactive Visitor Map (IVM)

The Forest Service Interactive Visitor Map (IVM) is a public-facing mapping application that helps visitors discover recreation opportunities, access forest information, and make informed decisions before visiting National Forests and Grasslands across the United States.

As part of a modernization effort, I helped transform the platform from a costly custom-developed solution into a scalable and maintainable commercial off-the-shelf (COTS) solution built using ArcGIS Enterprise, ArcGIS Online, and Esri Experience Builder.

Business Challenge

The existing Interactive Visitor Map environment relied on custom applications, numerous supporting services, and a large collection of FME workflows that required significant maintenance and operational overhead.

The Forest Service needed a more sustainable solution that would reduce costs, simplify administration, improve performance, and provide a better experience for both public users and agency staff.

My Role

  • Designed and implemented the ArcGIS Experience Builder solution.
  • Published and managed GIS services in ArcGIS Server and ArcGIS Online.
  • Developed workflow improvements and data integration processes.
  • Built Arcade expressions to improve popups and data presentation.
  • Collaborated with stakeholders, developers, and GIS specialists to resolve data and workflow challenges.
  • Created technical documentation and support materials for users and system administrators.

Technical Solution

The modernization effort replaced custom-developed applications with an Esri Experience Builder solution that leveraged ArcGIS Online and ArcGIS Server services.

Workflow improvements focused on reducing operational complexity, improving maintainability, and increasing performance while preserving existing business capabilities.

Additional enhancements included:

  • Integration of Forest Service vector tile basemaps.
  • Automation using FME workflows.
  • Twitter API integration for situational awareness data.
  • Offline mobile map package support for field use.
  • Enhanced popup user experiences using Arcade expressions.
  • Improved eBike data integration and management workflows.

Impact

The project modernized one of the Forest Service's most visible public mapping applications, improving performance, maintainability, and user experience for millions of visitors.

By reducing system complexity, eliminating redundant workflows, streamlining service architecture, and leveraging modern ArcGIS technology, the project created a sustainable platform that is easier to support and more cost effective to operate.

The resulting solution improved access to recreation information, supported better decision-making, and positioned the organization for future enhancements and growth.
