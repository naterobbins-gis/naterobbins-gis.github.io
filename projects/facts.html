Forest Service Activity Tracking System (FACTS)

The Forest Service Activity Tracking System (FACTS) serves as a critical enterprise repository for capturing, managing, and reporting information related to activities occurring across the National Forest System.

To improve data quality and decision-making, I collaborated with stakeholders, developers, and enterprise data teams to create a modern ArcGIS Online solution that transformed millions of activity records into actionable QA/QC dashboards, visualizations, and decision-support tools.

Business Challenge

FACTS contains millions of records submitted by units across the Forest Service. While the data supported critical planning and reporting functions, identifying incomplete, inconsistent, or inaccurate records was challenging and time consuming.

Program managers and planners needed an intuitive way to identify data quality issues, monitor trends, and prioritize corrective actions without requiring advanced database or GIS knowledge.

My Role

  • Collaborated with Forest Service stakeholders to define QA/QC requirements and workflows.
  • Worked closely with Enterprise Data Warehouse developers to integrate enterprise datasets.
  • Designed and developed ArcGIS Online Experience Builder applications.
  • Created interactive dashboards supporting data quality analysis.
  • Developed optimized data structures to improve application performance.
  • Provided technical guidance on enterprise GIS integration strategies.
  • Supported testing, refinement, and implementation of the final solution.

Technical Solution

The solution leveraged ArcGIS Online, Experience Builder, Dashboards, and enterprise data resources to provide a centralized environment for identifying and correcting data quality issues.

One of the project's most significant technical challenges was performance. Early versions relied heavily on enterprise feature layers containing millions of records, resulting in slow response times and poor user experience.

To address this challenge, I utilized ArcGIS Pro database tools and SQL query layer techniques to create optimized datasets specifically designed for analysis and reporting. The resulting architecture dramatically improved performance and transformed the application into a practical solution that end users could successfully adopt.

Performance Improvements

During development, application performance emerged as a major challenge. Large enterprise feature services were creating substantial delays and negatively impacting the user experience.

By redesigning the underlying architecture and leveraging optimized SQL query layers generated through ArcGIS Pro, data retrieval became significantly faster and more responsive. These improvements were essential to ensuring user adoption and long-term success of the application.

The resulting solution allowed users to interact with large datasets efficiently while maintaining access to critical enterprise information.

Impact

The FACTS QA/QC solution transformed raw enterprise activity records into meaningful visualizations and actionable information that supported improved data quality across the Forest Service.

By combining enterprise data integration, performance optimization, dashboard design, and user-focused application development, the project provided planners and decision-makers with the tools needed to identify issues quickly and focus improvement efforts where they would have the greatest impact.

The solution improved visibility into data quality, increased efficiency, and supported more reliable reporting and planning activities throughout the organization.
